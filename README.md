ROBO.720 – Group 4

This repository contains the exercises and completed work for ROBO.720 by Group 4 (Tuomas Karri & Peetu Lahtinen).
Repository structure
The repository is organized into folders for the course exercises and the completed exercises used for evaluation.

Exercises

The exercises folder is the main working area for the course exercises.
Group members should use this folder to work on and develop the solutions for the exercises.

Ready exercises for evaluation

The ready_exercises folder contains the completed exercises that are ready for evaluation.
Before an exercise is submitted for evaluation, make sure that the final version of the solution is placed in this folder.
